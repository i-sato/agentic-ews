# Brief proyek (tempel ke Project Knowledge Lovable; satu halaman)
PROTOTIPE saja, data fiktif. Aplikasi "EWS dan Laporan PK" untuk tim pelatihan talenta digital (bahasa Indonesia).
Tujuan prototipe: memperlihatkan layar dan alur untuk ditinjau pengguna. Bukan produksi.
Aturan: React + Vite + Tailwind + shadcn/ui + Recharts. Tanpa data asli. AI dimock (data statis), tampilkan label "Contoh".
Konsep: capaian = lulus/onboarding x 100 vs target 87. Onboarding = selesai modul >= 90%. Kumulatif tertimbang. Pembatalan tidak dihitung.
Banyak batch dipantau sekaligus; data diperbarui harian dari tautan sheet (tombol 'Perbarui' dan jadwal otomatis; simulasi). EWS punya fase waktu (Pantau/Aktif/Akhir/Selesai).
Layar: Login admin; Dashboard portofolio; Batch + unggah + hasil parsing nama berkas yang dapat diedit; Antrean Validasi; Laporan (draf -> tinjau -> setujui -> unduh); Aktivitas Agent (timeline langkah); Kartu Agent (+ sumber pengetahuan, data yang dikirim ke AI); Privasi dan Kepatuhan.
Status agent: Menunggu, Berjalan, Selesai, Selesai dengan peringatan, Perlu keputusan Anda, Gagal, Dibatalkan.
